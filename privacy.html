Boneyard RPG Viewer Field Guide

Privacy Policy

Effective August 26, 2026

What this Extension does

The Boneyard RPG Viewer Field Guide is a static reference for game onboarding, chat commands, class progression, systems, and regions.

Data collection

The Extension does not request Twitch identity linking, read or post chat messages, use cookies, run analytics, or collect, transmit, sell, or store personal information.

Local game data

The Extension is separate from the Boneyard RPG desktop launcher and game server. It cannot access broadcaster credentials, player saves, combat state, raids, or analytics.

Twitch

Twitch may process information under its own privacy policy when viewers use Twitch. That processing is controlled by Twitch, not this Extension.

Contact

Privacy questions may be sent to the public support address listed on the Extension’s Twitch directory page.
